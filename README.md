# RD INFRO TECHNOLOGY - Internship
Project Title: Task Manager App

Objective:
Create a simple full-stack Task Manager where users can:
- Add a task (title + optional description)
- Delete a task
- Mark a task as completed
- Persist tasks in a database

Minimum deliverable for internship Task 1:
- Project requirements document (this text)
- GitHub repository named "RD INFRO TECHNOLOGY" with a README
- A short demo video showing the README and repository

Tech Stack:
- Frontend: React.js
- Backend: Node.js + Express
- Database: MongoDB (Mongoose)
- Development tools: Git, GitHub, VS Code
